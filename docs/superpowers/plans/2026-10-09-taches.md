# Tâches, type reconnu, Brief et Pipeline — plan de mise en œuvre

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rubrique Tâches (semaine + liste, tâches HubSpot et tâches de l'OS), type de tâche reconnu d'après l'intitulé, Brief et Pipeline clarifiés.

**Architecture:** Le type est calculé une fois (copie HubSpot, création, modification) et stocké dans `taches.canal`. Un service `src/crm/taches.ts` porte liste, création et modification ; les tâches HubSpot passent par `writeVia` (double verrou existant), les tâches de l'OS sont modifiées directement. L'écran `Taches.tsx` lit une seule route par semaine.

**Tech Stack:** TypeScript, Fastify, Drizzle (Postgres), Zod, React 19, Vitest (testcontainers, jsdom).

**Spec:** `docs/superpowers/specs/2026-10-09-taches-design.md`

## Global Constraints

- Données de test fictives uniquement (domaines `.example`, noms inventés).
- Interface en français ; libellés de type : « Email », « Téléphone », « Action ».
- Aucune requête HubSpot réelle hors double verrou (`REAL_WRITES=on` + `instance:ecritures --on`) et sens `deux_sens`.
- Une tâche `natif` n'est jamais envoyée à HubSpot.
- Fuseau : Europe/Paris (helpers existants `zoned`, `jourDe`, `decaler` de `src/pilotage`).
- `npm run verify` vert avant chaque commit (exécuté dans le conteneur Node 24 sur ce poste).

## Review Focus

- Tâche sans échéance : visible dans la liste (en fin de tri), absente de la grille semaine, jamais « en retard ».
- Intitulé modifié dans l'OS sur une tâche HubSpot : le type est recalculé localement après écriture réelle, et la synchro suivante ne le contredit pas.
- Glisser une tâche HubSpot quand l'écriture est simulée : la carte revient à sa place et le message de simulation s'affiche.
- Tâche d'une autre instance : `PATCH /api/i/<a>/taches/<id de b>` renvoie 404.
- Échéance envoyée par l'écran en heure de Paris : stockée et renvoyée en ISO UTC sans décalage d'une heure.

  - `listTaches(db, instance, { du: string; au: string }, deps): Promise<{ taches: TacheVue[]; enRetard: TacheVue[]; sansEcheance: TacheVue[]; rdv: Evenement[]; rdvEtat: 'ok' | 'non_configure' | 'erreur'; hubspot: boolean; ecrit: boolean }>` — `du`/`au` jours `YYYY-MM-DD` Paris, `au` inclus ; `enRetard` = non faites, échéance avant `du` ; `sansEcheance` = non faites sans échéance.
